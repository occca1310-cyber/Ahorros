# 💰 App de Ahorros

Administrador de ahorros personal con login multiusuario.

## Funciones
- Login con nombre y contraseña
- Multiusuario — cada quien sus ahorros
- Agregar y retirar dinero
- Meta de ahorro con barra de progreso
- Historial de movimientos
- Funciona sin internet (PWA)
- Instalable en el celular

## Tecnologías
- HTML
- CSS
- JavaScript
- localStorage
